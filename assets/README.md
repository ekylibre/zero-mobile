# Assets

Ce dossier contient les images statiques bundlées dans l'app.

À fournir avant le premier build EAS (P1 → P8) :

- `icon.png` — 1024×1024, icône principale (sera dérivée pour iOS/Android par Expo)
- `splash.png` — 1242×2436 ou supérieur, image du splash screen
- `adaptive-icon.png` — 1024×1024 sur fond transparent (Android adaptive icon)

En P1, des assets placeholder neutres suffisent. Les assets définitifs
viennent de l'équipe design Ekylibre, en P8 (polish).
